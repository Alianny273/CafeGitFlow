# ☕ Proyecto CafeMambru (Git Flow)

Repositorio desarrollado para la actividad integradora de control de versiones aplicando la metodología profesional de **Git Flow**.

## 🚀 Descripción del Proyecto
Sistema web para una cafetería que incluye catálogo de productos, carrito de compras y secciones interactivas, estructurado bajo buenas prácticas de desarrollo frontend y control de cambios.

## 📌 Estructura de Ramas (Git Flow)
- **`main` / `master`**: Rama de producción con las versiones estables liberadas (`v1.0.0`, `v1.0.1`, etc.).
- **`develop`**: Rama de integración donde se unifican las nuevas funcionalidades (*features*).
- **`feature/*`**: Ramas temporales para el desarrollo de características individuales.
- **`release/*`**: Ramas de preparación para lanzamiento de nuevas versiones.
- **`hotfix/*`**: Ramas de parcheo rápido para corregir errores críticos en producción.

## 🛠️ Tecnologías Utilizadas
- HTML5, CSS3, JavaScript (Vanilla)
- Git & GitHub / Git Flow
- XAMPP / Localhost
